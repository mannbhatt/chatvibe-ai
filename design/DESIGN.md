# ChatVibe AI Design System

## Core Aesthetic
Playful, fast, colorful, premium.
Feels like Instagram x Apple Messages x TikTok.
Mobile-first (iOS style).

## Typography
- Font Family: Plus Jakarta Sans (Main)

## Spacing Grid
- Base unit: 8pt
  - 1 = 8px
  - 2 = 16px
  - 3 = 24px
  - 4 = 32px

## Radii
- Cards: 24px
- Buttons: 16px
- Chat Bubbles: 18px

## Colors (Initial Palette)
- Primary: Vibrant Purple / Pink gradient aesthetic
- Background: Very light gray/white (iOS typical)
- Surface: White (Cards)
- Text: Dark Charcoal
- Secondary: Subtle gray for muted text
